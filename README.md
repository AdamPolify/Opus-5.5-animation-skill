# Opus 5.5 Animation Skill

A Claude skill for turning static designs into animated brand pieces:
3D ticket launches, animated X profiles/banners, and Figma frames where
every section moves — exported as a live page and a smooth MP4.

## Install
1. Download `SKILL.md`
2. Put it in a folder named `ticket-style-motion`
3. Add it to Claude as a skill

## What's inside
- Pulling exact assets and positions from Figma
- Motion techniques: bending 3D paper, rolling numbers etc
- Fixing laggy animations
- Frame-by-frame MP4 export
